# AI based interaction 
Maybe a very small local LLM can be used for analyzing stuff like soundings and get text. 
This text should be converted to voice as well. 

Analysis of surroundings can be done by getting surrounding objects' properties and then process them. 
Ideally, the meshes itself should be analyzed. But it is very expensive. Hence, use sub-meshes' properties which are manually labelled by 3D world designers. 

context can be what happened recently and story stuff. The models needs to be custom training and fine tuning as well.
