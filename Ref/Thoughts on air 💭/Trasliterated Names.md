###### "Trans-Literated" and not "Translated"

If names are to be translated it wuld be an issue for players of different languages to communicate. And if we even limit the translation to a single language, it might help the best, but would highly dilute the culture(as names are an art and a corner stone to this culture) also highly hinder the players' will to understand this culture. But Trans-Literateration is the best balance. It additionally gives positive reinforcement for the yser that they are learning a culture and also if thus were also reinforced, it would also help with the player understanding and remembering well. Though the downside i feel is the number of languages to involve. As more number of languages will cause the same issue of communication among players via the community. Its best to limit to one or two transliterated languages. 

The Names to be transliterated could invlove NPC names, place names, object names, etc. This must appear everywhere, in all menu, logs, guides, etc in all UI. This transliterated names play a huge amount of effort in giving vibe of the character. Especially Elevation. If not donewell, it'll not give the same impact as the name is said.
